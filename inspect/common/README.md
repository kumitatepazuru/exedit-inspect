# アドレス図鑑 / 共通実装

`data/exedit.auf`(32bit PE、`ImageBase = 0x10000000`)のうち、本プロジェクトで
**同定済みのアドレスを全部1箇所に集めた索引**。アドレスはすべて VA
(`RVA = VA - 0x10000000`)。

各行の「詳細」は根拠と検算スクリプトのある README を指す。まず概要でアタリを
付けて、必要なときだけ詳細へ飛ぶための表である。粒度は**関数・テーブル・
グローバル単位**で、「この1命令がこう分岐する」といった命令レベルの引用は
各エフェクトの README 側にある。

未知のアドレスを引くときは:

```
uv run main.py tools.xrefs --addr 0x........      # 参照元とそのエフェクトを推定
uv run main.py tools.disasm --addr 0x........ --size 0x100
uv run main.py tools.decompile --addr 0x........ --calls
```

## 共通実装ドキュメント

エフェクトをまたいで同じ実装が使われている部分は、個別 README から切り出して
以下にまとめてある。**新しいエフェクトを解析するときは、まずここを読めば
同じところを読み直さずに済む。**

- [`filter_registration.md`](filter_registration.md) ―― エフェクト登録構造体と
  ディスパッチ。`FILTER_DLL` 配列、オブジェクト効果 / フレームフィルタの2登録
  モデル(`fp->flag & 0x20`)、`FILTER_PROC_INFO` の exedit 独自オフセット、
  `fp+0x60`/`fp+0x64` の差し替えとマルチスレッド起動、`ex_data` のレイアウト。
- [`param_scaling.md`](param_scaling.md) ―― トラックバーの生値と UI 表示値の
  対応。`+0x74` 拡張ブロックの4スロット(表示スケール / グループ化マーカー /
  ドラッグ範囲)、全エフェクト分の一覧、マジックナンバー除算 `0x10624dd3`。
- [`box_blur.md`](box_blur.md) ―― アルファ加重(プリマルチプライ)平均と分離型
  ボックス平均。**ガウシアン核はどこにも無い**こと、色を `sum_a` で割る意味、
  除数の3変種がそのまま端の扱いの違いであること、スライディングウィンドウの
  3フェーズと既知の overrun。
- [`blend_modes.md`](blend_modes.md) ―― 矩形転送 `table[0x44]` / 矩形クリア
  `table[0x48]` と合成モード語の分解。ブレンド関数テーブル `0x1009fbb0`、
  加算 / 通常 / 単純コピーの実際の式。
- [`canvas_growth.md`](canvas_growth.md) ―― キャンバス拡張の4方式と
  `サイズ固定`。ワーカーが枠外に書く / `table` で事前拡張する / オフスクリーン
  描画 / 矩形を計算して置き直す、の使い分けと最大キャンバスサイズ。
- [`exp_log_curve.md`](exp_log_curve.md) ―― `ぼかし` の `光の強さ` と `発光` の
  `拡散速度` が共有する指数/対数空間の輝度カーブ。**平均するか加算するか**の
  1点だけで上界の有無が分かれること、色差が 1/16 に量子化される代償。
- [`rgb_ycbcr.md`](rgb_ycbcr.md) ―― `光色の設定` の保存形式(bit24)と
  RGB→YCbCr(BT.601 フルレンジ、Q14)。`発光` と `閃光` で使い方が正反対である
  こと、暗い光色で効果が消える条件。
- [`integer_semantics.md`](integer_semantics.md) ―― C / x86 の整数意味論と CRT
  ヘルパー。`idiv`(0方向切り捨て)と `sar`(floor)が同じ式に同居すること、
  **色差でだけ結果が食い違う**理由、x87 の double 除算。
- [`lut_tables.md`](lut_tables.md) ―― `0x1006c680` が生成する三角関数テーブル
  3本。イージングテーブル `0x101dcf78` の生成式と、逆引き参照が同じ配列の
  左右反転にすぎないこと。
- [`border_correction.md`](border_correction.md) ―― `境界補正` を持つ3つの
  抜き系エフェクトが共有するマット後処理。垂直/水平ボックス平均 → 元マップとの
  積 → 伸張定数 `A = 4096 - 4096/r` / `B = 4096 mod r`。**式は同じでも
  「何をぼかすか」が違うと結果の意味が変わる**こと(`カラーキー` が半透明を
  潰すのはこれ)。

### 境界ぼかし ― [`inspect/boundary_blur`](../boundary_blur/README.md)

| アドレス     | 役割                      | 概要                                                                                                          |
| ------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `0x10011b00` | `func_proc`               | 半径計算(`ぼかし` と同一式)、`w/2`・`h/2` への独立クランプ、チェックボックスによるワーカー選択                |

| `0x10012200` | ON: 横ボックス平均+再合成 | 末尾に非線形しきい値カーブ `alpha' = (a*t)>>12, t = ((a*blurred)>>11) - 4096`                                 |

登録はオブジェクト効果1個のみ(フレーム版が存在しない)。
